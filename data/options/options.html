Read Aloud

Reads the current page aloud paragraph by paragraph with highlighting. The main controls live in the floating bar that appears when you start reading (toolbar icon or context menu).

Default engine

Browser voices: choose the language / voice in the page's floating bar while reading. Leave blank to use the browser default.
The Edge TTS server must expose an OpenAI-compatible /v1/audio/speech endpoint. Add the host to Allow this server below when it is not on localhost.
